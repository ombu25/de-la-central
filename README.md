# De la Central a Tu Casa 🌿

Tienda en línea para pedidos semanales de frutas, verduras y frutos secos.

## Cómo funciona
- El cliente arma su pedido el **viernes**
- Recibe su entrega el **domingo**

## Features
- Catálogo completo con precios
- Opción de ½ KG en productos por kilo
- Búsqueda en tiempo real
- Agregar productos fuera del catálogo
- Carrito con nombre del cliente
- Exportar pedido a Excel
- Compartir pedido por WhatsApp
